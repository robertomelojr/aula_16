# SQL model, CRUD e revisão de POO
#### Estudando biblioteca e aplicação de exemplo básico para entendimento do funcionamento da lib.
- Principais vantagens: Robustez do Pydantic e do SQLAlchemy.
- Desvantagem: Como tem mais dependências acaba sendo uma lib maior.

- Apenas com um table=True já identifica a estrutura como um sql e já temos abstrações que levariamos horas para desenvolver do zero.
- Mesmo co ma facilidade de utilização é importante sempre consultar a documentação para um claro entendimento do que está sendo feito no código.
